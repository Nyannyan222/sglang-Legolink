# Code map

Architecture component → source file → class / function → caller → callee. Host paths are relative to the repository root; runtime paths are
relative to `patched_sglang_files/python/sglang/srt/` (a checkout of the patched SGLang built by `scripts/build_patched_sglang.sh` has the same
layout under `python/sglang/srt/`).

Line numbers are those of the files as published here and were taken from the audit that preceded the publication; they are a navigation aid, and
the symbol names are authoritative. `tests/test_architecture_stage_map.py` pins the stage → file → symbol mapping (`noc_context_manager/architecture_stages.py`),
so a renamed symbol fails the test suite rather than silently invalidating this page.
